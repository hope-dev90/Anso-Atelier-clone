# Agency site (React + Vite)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

Routes: /, /services, /clients, /work, /work/:slug, /about, /contact.
Edit content in src/data.js and src/pages/. Styles are in src/styles.css. Put images in public/images/.
For hosting, configure your server to serve index.html for all routes.
